# Correlação de Ativos

## Sobre o projeto

Este é o meu primeiro projeto pessoal desenvolvido em Python.

Como faço day trade, decidi criar uma ferramenta relacionada ao mercado financeiro e aos estudos que realizo diariamente. O objetivo é analisar a relação histórica entre diferentes ativos utilizando dados do Yahoo Finance e visualizar essas informações através de gráficos.

## Objetivo

Estudar a relação histórica entre ativos financeiros para entender como seus movimentos se comportam ao longo do tempo.

A primeira análise compara:

- Ibovespa
- Dólar (USD/BRL)

## Atualização: Análise durante a pandemia

Nesta atualização, adicionei uma análise específica do período da pandemia em 2020, comparando o comportamento do Ibovespa e do dólar.

Além do gráfico com os preços reais dos dois ativos, foram calculados:

- maior queda do Ibovespa no período
- maior valorização do dólar no período
- datas em que esses movimentos ocorreram

Essa etapa teve como objetivo transformar a visualização em uma análise mais objetiva, utilizando Pandas para filtrar períodos, encontrar máximas e mínimas e calcular variações percentuais.
